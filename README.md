# Landing page — Análise de Dados com IA

Página estática pronta para publicação na Vercel.

## Antes de publicar

Abra `script.js` e substitua o valor de `HOTMART_CHECKOUT_URL` pelo link final do checkout da Hotmart:

```js
const HOTMART_CHECKOUT_URL = "https://pay.hotmart.com/SEU-LINK";
```

Depois, publique a pasta do projeto como um projeto estático na Vercel. Não é necessário instalar dependências ou executar um build.
